# Entrega: programa en lenguaje ensamblador

**Plazo:** hasta el **martes 24 de noviembre de 2026 a las 10:00** (hora de Madrid). Para esa hora el *pull request* tiene que estar enviado y aceptado, porque los programas se presentan ese día en clase.

Los *pull request* que lleguen después de las 10:00 se cierran automáticamente como fuera de plazo.

Desarrolla un pequeño programa en lenguaje ensamblador con el [simulador de ensamblador](http://schweigi.github.io/assembler-simulator/index.html) y súbelo a esta carpeta.

## Cómo subirlo

1. Entra en GitHub con tu cuenta (si no tienes, créala gratis en [github.com](https://github.com/signup)).
2. Abre esta carpeta, `Entregas/Programa en ensamblador`, y pulsa **Add file → Upload files**.
3. Sube tu programa como archivo de texto con el nombre `Apellido Nombre.asm` (por ejemplo, `Pérez Ana.asm`).
4. Abajo, en el mensaje, escribe tu nombre y pulsa **Propose changes** y luego **Create pull request**.

GitHub hace una copia del repositorio en tu cuenta y envía tu archivo como propuesta (*pull request*). La profesora la revisa y la incorpora a esta carpeta.

## Qué debe incluir

- Al principio del archivo, en comentarios (líneas que empiezan por `;`), tu nombre y una frase que explique qué hace el programa.
- El código completo, que debe ejecutarse sin errores en el simulador.
